# SAS Congo — Démonstration Agence Elite

Site statique en HTML, CSS et JavaScript. Servir le dossier `dist` avec un serveur statique. Aucun build requis.

Les formulaires sont des démonstrations : aucune donnée ni candidature n’est transmise. Les photographies sont des illustrations issues d’Unsplash. Le logo est fourni par le propriétaire du projet.

## Déploiement
Publier le dossier `dist` sur Netlify ou Cloudflare Pages.

## Mise à jour
Le contenu, les styles et les interactions sont dans `dist/index.html`. Les images sont dans `dist/assets`. Le cahier des charges fourni est conservé dans `docs/BRIEF.md` pour la future version multipage bilingue. Cette première démo ne réalise pas encore ce cahier des charges complet.
